#### Added

- A native Go backend: `ambxst` is now a single binary that supervises Quickshell, `axctl` and `wl-paste`, replacing `cli.sh` and all Python scripts.
- Core services moved to the backend: network, brightness, gamemode, power profile, caffeine and night light, plus native Go image thumbnails — ImageMagick is no longer needed.
- A screenshot engine ported from [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) (MIT): `wlr-screencopy` capture with native 8/10-bit PNG encoding, and IPC services for screenshots and the `gpu-screen-recorder` lifecycle.
- An interactive layer-shell loupe color picker (also ported from DMS), with pure-Go barcode scanning covering QR, EAN/UPC, Code128/39/93, Codabar, ITF, Aztec and DataMatrix — no more `zbar`.
- OCR and QR extraction tools that reuse the screenshot overlay for region selection.
- New CLI commands: `ambxst wallpaper`, `ambxst preset`, and install/remove subcommands for the niri and MangoWC compositors.
- Niri and MangoWC support in the generated compositor config, alongside Hyprland.
- Monocle layout, available in the cycle and through keybinds.
- Configurable terminal; kitty is no longer a hard dependency.
- GTK applications now follow the dark mode of the generated theme.

#### Improvements

- Big performance and memory pass: jemalloc returns memory to the OS on startup, dashboard tabs unload on close with cached wallpaper thumbnails, and heavy work (wallpaper, AI models and chat history, lockscreen frames, clipboard database, notification history) is deferred or lazy-loaded.
- Compositor settings like border colors, rounding and shadows now apply instantly via live config eval, while still persisting across restarts.
- The workspace slide animation runs parallel to the bar's orientation and persists across restarts.
- Screen recording gained a toggle keybind and post-save notification actions.

#### Fixes

- Bar flyouts are now mutually exclusive within the same group instead of stacking on top of each other.
- Player metadata width is constrained so long titles elide correctly.
- Race condition when locking the session right after suspend.
- Monitor focus issues.
- Settings window instantly closing in secondary monitors.

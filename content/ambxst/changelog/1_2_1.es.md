#### Mejoras

- El instalador ahora descarga binarios precompilados desde GitHub Releases en lugar de compilar localmente: instalación mucho más rápida, sin necesidad de la toolchain de Go, con verificación SHA256 y soporte para `amd64`/`arm64`.
- Los releases ahora los compila automáticamente el CI con cada tag de versión.

#### Eliminado

- Dependencias residuales de Python: `pipx`, paquetes sueltos de Python y el paso de `pipx ensurepath` — todo lo que las necesitaba vive en el backend Go desde la 1.2.0.

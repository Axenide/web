#### Improvements

- The installer now downloads prebuilt binaries from GitHub Releases instead of compiling locally: much faster setup, no Go toolchain required, SHA256 verification, and `amd64`/`arm64` support.
- Releases are now built automatically by CI for every version tag.

#### Removed

- Leftover Python dependencies: `pipx`, standalone Python packages and the `pipx ensurepath` step — everything that needed them lives in the Go backend since 1.2.0.

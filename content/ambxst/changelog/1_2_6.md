#### Reverted

- Brightness control reverted to the pre-1.2.5 implementation. The 1.2.5+ rewrite, which routed writes through the `axctl` daemon over a long-lived socket subscription and gated them with a two-flag `userControlled` / `pendingOsd` system, introduced noticeable input lag on laptops that the previous direct `ddcutil` / `brightnessctl` path did not have. The shell now invokes those tools via a single reusable `Quickshell.Io.Process` per monitor, the way it did before 1.2.5.

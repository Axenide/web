#### Fixes

- Brightness value stopped rebounding on DDC/CI displays. The `Event.BrightnessChanged` subscription added in 1.2.5 echoed every write back through QML, but DDC quantizes reads to whole-percent steps, so a request for 80 % could read back as 79 % — the slider then jumped back and forth between the optimistic value and the read-back. A settle window of 1500 ms with a 2 % tolerance now filters echoes of our own writes; only external changes (keybinds, idle hook, scripts) cross the threshold.

- Slider feedback feels snappier. The DDC debounce dropped from 300 ms to 100 ms, so dragging a DDC slider no longer lingers after release.

- The OSD no longer re-animates from no-op subscription echoes. `applyReportedBrightness` now skips assignments when the value matches the current state, so the OSD icon rotation and scale only fire on real changes.

#### Fixed

- Lockscreen no longer got stuck after a successful login with GameMode on: the unlock timer derived its interval from `Config.animDuration`, which is `0` under GameMode, and a QML `Timer` with interval 0 never fires. It now guarantees a minimum interval.
- GameMode works again. It is now a render layer over the compositor's TOML config: while active, every config write emits performance-first appearance values (no animations, blur, shadows, gaps or rounding, 1px border), and on exit the user's values are restored live.

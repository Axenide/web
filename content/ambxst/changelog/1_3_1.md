# MODS VERSION BYPASS

#### Added

- The mods system gained a global **Bypass Ambxst version check** toggle in Settings → Mods. Some mods declare a compatibility range that ends before 1.3.0 (for example `1.2.6`), which blocked them from enabling even when they work fine. Waiting for every author to bump their range is not a great experience, so the check can now be relaxed in one place instead of per mod.

#### How it works

- With the bypass on, a package outside its declared `compatibility.ambxst` range composes and enables normally.
- The status keeps reporting bypassed packages as incompatible, so it is always visible which mods are technically out of range.
- The toggle is a state flag: it applies from the next build, and a failed build still leaves the running shell untouched.
- The same operation is available as `ambxst mods bypass on|off`, and `ambxst mods list` shows when the check is bypassed.

This extends the mod manager from [PR #230](https://github.com/Axenide/Ambxst/pull/230).

### SECURITY UPDATE

**This is a security release. Update as soon as possible.**

#### Fixes

- **Command injection via Wi-Fi SSID** (High): a malicious network name broadcast nearby could run shell commands as your user when connecting to it with a password. The SSID is now passed to `nmcli` without any shell involvement. Found and reported by 0xr3ngar through responsible disclosure.
- **IPC squatting**: the keybind FIFO and the axctl socket now live in the per-user runtime dir (`$XDG_RUNTIME_DIR`) instead of the shared `/tmp`, and axctl now verifies peer credentials on every connection. A second local account can no longer plant files that block or impersonate them.
- The clipboard rewrite in 1.3.2 had already removed two related injection vectors in the clipboard pipeline; this release closes the remaining ones.

#### Fixes

- **Screenshots now capture the frozen frame**: the save used to re-capture the live screen the moment you confirmed, so the result didn't match the frozen preview and on some systems it caught the selection toolbar in the shot ([#156](https://github.com/Axenide/Ambxst/issues/156)). Captures are now cropped from the exact in-memory buffer the preview displays — what you see is what you get.
- The freeze buffer is shared with OCR/QR and window selection too, so those reads are consistent with what was on screen when the tool opened. The daemon releases the memory when the tool closes.
- **Wallpaper folders with symlinks now work**: the wallpaper scanner ignored symlinked directories, so wallpapers kept in dotfiles-style linked folders never showed up. Scans now follow symlinks (with loop protection), and `~` in wallpaper paths is expanded in the dashboard, the theme panel and the CLI.
